# mechanic — memory

Empty by design. Lessons are **earned**, never pre-written.

Each lesson is one file:

```
<one-line summary of the lesson>

<what happened, and why it mattered>

Ref: DEF-YYYY-MM-DD-NNN
```

Lessons arrive here only through the defect-routing protocol: a real failure is classified, assigned to the agent that could have caught it earliest, and converted into a lesson plus a regression check. Only Librarian writes here.

See `../../../examples/lesson-format/` for illustrative samples and `CONTRIBUTING.md` for why this rule exists.
